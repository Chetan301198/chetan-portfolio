# Chetan Bhalerao — Portfolio

Personal site for [Chetan Bhalerao](https://www.linkedin.com/in/chetan1998), a frontend developer in Mumbai.

Experience is taken from the public LinkedIn profile. Project cards and the GitHub usage section read live data from [`Chetan301198`](https://github.com/Chetan301198).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

The app is a standard Next.js project. Push this repo to GitHub, then connect it to Vercel (or run `npm run build` / `npm start` on any Node host).
